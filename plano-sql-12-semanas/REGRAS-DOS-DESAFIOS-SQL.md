# Regras dos desafios de SQL

Todo fim de semana tem uma prova de SQL no formato de entrevista. As regras gerais (o que pode, o que não pode, o que avaliam) são as mesmas do plano de PHP: leia `plano-php-12-semanas/REGRAS-DOS-DESAFIOS.md`.

Diferenças comuns em teste de SQL:

- **Editor online** (CoderPad, HackerRank, DB Fiddle) com o banco já carregado: você roda as consultas e vê o resultado. Não tem autocomplete.
- **Papel ou quadro**, sem rodar nada: o entrevistador quer ver se você escreve SQL que funciona de primeira e se explica o raciocínio.
- **Leitura de consulta**: te mostram uma consulta pronta e pedem para explicar o que ela faz, achar o erro ou deixar mais rápida.
- Documentação do Postgres costuma ser permitida no editor online; no papel, não.
- IA não é permitida.

Como simular aqui: responda no arquivo `respostas.php` da pasta do desafio, com **a conexão PDO escrita à mão** e uma consulta por pergunta, imprimindo o resultado. Cronometre. Quando o formato for papel, escreva primeiro em `respostas-papel.sql` sem rodar, e só depois confira no banco.
