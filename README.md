# Estudos dev júnior: PHP e SQL

Material de revisão e prática para vaga de desenvolvedor júnior PHP, com um caminho até nível pleno em SQL.

## O que tem aqui

| Pasta | O que é |
| --- | --- |
| `aula-php/` | A aula de revisão: PHP moderno, orientação a objetos, SQL, PDO, HTTP, Laravel, segurança, testes, Git e IA. |
| `aula-sql/` | A aula de SQL, do SELECT às window functions, com a conexão PDO escrita à mão. |
| `plano-php-12-semanas/` | 12 semanas, 5 dias cada, cobrindo a aula inteira toda semana com um tema diferente, e um desafio de entrevista ao vivo por fim de semana. |
| `plano-sql-12-semanas/` | 12 semanas só de SQL, com bancos e dados prontos, exercícios de nível pleno e uma prova por fim de semana. |

Todos os arquivos de exercício já estão criados e **vazios**. Os poucos que vêm preenchidos (código legado para refatorar, código com bug, dados em CSV, artigos, consultas com erro) estão marcados como **(fornecido)** nos READMEs.

## Por onde começar

1. Leia `aula-php/aula-php-junior.md` inteira uma vez, sem pressa.
2. Siga "Antes da semana 1" em `plano-php-12-semanas/README.md`, incluindo subir o banco de treino.
3. Comece a semana 1 numa segunda-feira.
4. No primeiro fim de semana, leia `plano-php-12-semanas/REGRAS-DOS-DESAFIOS.md` antes do desafio.

## Revisão

Quando fechar uma semana ou um desafio, mande o código e o arquivo `NOTAS.md` para revisão. Vou comentar como revisaria o PR de um júnior numa empresa.
