# 20 perguntas de entrevista para júnior PHP

Faça em ordem aleatória. Resposta ideal: 30 segundos a 1 minuto, com um exemplo seu quando der.

1. Qual a diferença entre `==` e `===`?
2. O que é injeção de dependência? Dê um exemplo de onde você usou.
3. Interface ou classe abstrata: quando usar cada uma?
4. O que é SQL injection e como você evita?
5. Diferença entre `INNER JOIN` e `LEFT JOIN`.
6. `WHERE` vs `HAVING`.
7. O que é uma transação? Dê um exemplo em que ela é obrigatória.
8. O que é N+1 e como você resolve no Laravel?
9. O que acontece quando uma requisição chega numa aplicação Laravel?
10. 401 vs 403 vs 404.
11. O que é idempotência? Quais métodos HTTP são idempotentes?
12. O que é XSS e como o Blade protege?
13. O que é CSRF?
14. Como você guarda senhas?
15. Diferença entre teste unitário e teste de feature. O que você testaria primeiro num sistema de pedidos?
16. Merge ou rebase? Quando usar cada um?
17. Como você garante que um usuário não vê o dado de outro?
18. O que é RAG? E tool calling?
19. Como você usa IA para programar, e como garante que o código está certo?
20. Conte um bug difícil que você resolveu: como achou a causa e como provou a correção.
